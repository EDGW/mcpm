# Server operations

Server operation 处理服务端目录里的数据：读取服务端是什么、写入它的登记和配置，以及保存、比较、
恢复 `mods/` 的快照。服务端目录所在的机器称为 Host（见 [mcpm 命令](../../../mcpm/docs-zh/README.md)
中的术语）。

| 页面 | 内容 |
| --- | --- |
| [基础](basics.md) | 读取服务端信息、识别并初始化服务端、准备 Remote 服务端 |
| [Stash](stash.md) | `mods/` 快照的创建、切换、比较、列出、校验和删除 |

## 在哪里执行

operation 总是在服务端目录所在的 Host 上执行，路径参数就是这台 Host 上的路径。调用方不需要关心
这台 Host 是本机还是远端：同一个 operation 在两种情况下行为一致。

如果调用方指定的是 Remote workspace，调用方会先把它换成对应的远端服务端目录，再执行 operation。
所以 operation 看到的永远是一个真实的服务端目录。

返回的路径保留 Host 自己的写法（例如 Windows 路径），不会被转换成调用方平台的写法。

## 进度

耗时的操作在工作过程中持续报告进度，结束时给出一个最终结果。调用方不再读取时，操作随后停止；
已经写入的文件保留。

## 失败

失败要么使整个操作失败，要么只影响结果中的某一项：

- 整个操作失败：操作报错，没有结果。
- 单项失败：例如一次列出多个快照时，其中一个读不出来。这一项带着错误出现在结果里，其余各项仍然
  正常返回，调用方可以保留成功的部分，同时逐项报告失败。

两种失败都保留完整的错误链，细节见 [mcpm-exec 错误模型](../../../mcpm-exec/src/docs-zh/error.md)。

连接中断不会撤销已经写入的文件。写入或传输失败后，服务端目录里的实际内容才是真实状态，
继续之前应先检查。
